- `math.validation.counting-conventions`: Counting convention audit
- `math.validation.boundary-check`: Boundary and degeneracy checks
- `math.validation.independent-recompute`: Independent numerical cross-check

- `math.revision.difficulty-preserving`: Difficulty-preserving repair
